# Security policy

Please do not disclose suspected vulnerabilities in Lumi or this site in public issues or pull requests.

Report them with GitHub private vulnerability reporting on Lumi's repository, `nieve-consulting/lumi` (its **Security** tab, **Report a vulnerability**). If you can't use GitHub, contact Nieve through [Nieve's contact page](https://www.nieveconsulting.com/contact), request a private security reporting channel, and wait for a private route before sending sensitive details. [Reporting vulnerabilities](https://docs.lumi.nieve.ai/security/reporting-vulnerabilities) describes what to include.

Mistakes in the docs that could lead operators into an insecure setup are welcome as ordinary issues or pull requests, as long as they don't describe an exploitable vulnerability in a live installation.
